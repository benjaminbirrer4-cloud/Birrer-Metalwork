# Birrer Metalwork – Webseite

Statische Firmenwebseite mit Produktkatalog und Offertanfragen.

## Inhalt
- `index.html`: Webseite
- `images/`: Logo und Referenzfotos
- `CNAME`: geplante Domain www.birrermetalwork.com
- `robots.txt`, `sitemap.xml`: Suchmaschinen-Hinweise

## Veröffentlichung
1. Dateien **aus diesem Ordner** in das Hauptverzeichnis eines öffentlichen GitHub-Repositories hochladen.
2. In GitHub unter Settings > Pages die Veröffentlichung von `main` / `(root)` aktivieren.
3. Im Domainanbieter DNS für `www` einen CNAME auf `<GitHub-Benutzername>.github.io` setzen (ohne https://).
4. In GitHub Pages `www.birrermetalwork.com` als Custom Domain eintragen und nach DNS-Prüfung HTTPS aktivieren.
5. Für die Weiterleitung der Root-Domain `birrermetalwork.com` die GitHub-Pages-Dokumentation zu Apex-DNS beachten.

**Wichtig:** Die Domain und die DNS-Einträge wurden noch nicht verbunden; die Webseite ist noch nicht online. 
Die Webseite nimmt Anfragen per E-Mail entgegen, keine Onlinezahlungen.
